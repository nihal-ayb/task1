# EC2 System Monitoring Script

## Project Overview
A Bash-based monitoring script developed for an Ubuntu Amazon EC2 instance. It collects basic system information and displays it in a clearly formatted report.

## Features
- Displays the current date and time.
- Displays the EC2 hostname.
- Reports CPU usage.
- Displays memory usage.
- Reports disk usage.
- Lists currently running system services.
- Saves monitoring output to a log file.
- Supports daily automated execution using cron.

## Project Files
- `monitor.sh` — Main monitoring script.
- `monitor_logs.txt` — Sample output generated by the monitoring script.

## Requirements
- Ubuntu Linux
- Bash shell
- `top`, `free`, `df`, and `systemctl`
- Git (for version control)
- Cron (for scheduling)

## How to Run

Make the script executable:

```bash
chmod +x monitor.sh
```

Run the monitoring report:

```bash
./monitor.sh
```

Save the report to the log file:

```bash
./monitor.sh >> monitor_logs.txt 2>&1
```

## Automated Execution
The script can be scheduled to run daily at 9:00 AM using crontab:

```cron
0 9 * * * /home/ubuntu/shell-assignment/monitor.sh >> /home/ubuntu/shell-assignment/monitor_logs.txt 2>&1
```

View scheduled tasks:

```bash
crontab -l
```
